# Продуктовая дорожная карта: QR-меню, оптимизация процессов и ИИ для HoReCa

Дата: 30.10.2026. Документ собран по материалам `research/11–20`, в первую очередь по `18-unit-economics.md` и `19-tech-stack.md`. Помета **[оценка]** означает наше допущение, которое нужно проверить на первых клиентах. Все цены указаны в рублях.

---

## 1. Главный принцип

QR-меню само по себе почти не приносит прибыли: при цене 1–3 тыс. ₽/мес валовая маржа 10–50 %, а отток 20–30 % заведений в год (18, 17). Поэтому QR-меню используем как **входной продукт**, а зарабатываем на **ИИ-модулях и внедрении процессов «под ключ»** поверх кассы клиента (iiko, Poster, r_keeper). Свой код пишем только там, где появляется отличие от конкурентов или повторяемая маржа. Всё остальное берём у партнёров или делаем на white-label.

Ключевые ограничения, которые определяют архитектуру:
- **152-ФЗ.** С 01.07.2025 персональные данные граждан РФ первично обрабатываются в РФ. Для данных гостей используем только GigaChat или YandexGPT. DeepSeek и Claude допустимы только в задачах без персональных данных (19, 18).
- **Каналы.** Telegram замедляют, WhatsApp в РФ ограничен, а MAX по дневному охвату обогнал Telegram (16). Поэтому каждый бот сразу делаем под Telegram, MAX и VK, а для СНГ добавляем WhatsApp.
- **Голос.** SaluteSpeech с 15.07.2026 работает с новыми юрлицами только по индивидуальному договору. Основной провайдер речи — Yandex SpeechKit (19).

## 2. Делаем сами или берём у партнёров

| Компонент | Решение | Почему | Партнёр / замена |
|---|---|---|---|
| QR-меню (веб-витрина, админка, мультиязычность, аллергены) | **Сами** | Это ядро продукта и источник данных для всех ИИ-модулей. Разработка простая: 6–10 ч на внедрение (18) | На первые 30 дней можно взять white-label чужого QR-меню |
| Импорт меню и стоп-листов из iiko и Poster | **Сами** | Главный довод «работаем поверх вашей кассы». iiko растёт на 59 % г/г (17) | — |
| r_keeper | **Позже, через дилеров** | Доступ к API зависит от дилеров, интеграция займёт 3–5 недель (19) | Дилеры r_keeper |
| Отправка заказов в кассу, оплата со стола | **Партнёрство на первом этапе** | Сложно, нужны эквайринг и фискализация | Эквайеры с СБП, модули кассовых экосистем |
| Мульти-канальный бот (Telegram, MAX, VK) с RAG по меню и FAQ | **Сами** | Наше главное отличие и маржа 60 % и выше. Новый канал подключается за 3–5 дней (19) | В первые 30 дней работает на no-code (n8n, Salebot) |
| LLM | **Покупаем API** | GigaChat Lite стоит 0,065 ₽ за 1000 токенов, бот обходится в 150–1 200 ₽/мес (18) | GigaChat (основной), YandexGPT (резерв) |
| Распознавание и синтез речи, телефония | **Покупаем API** | Голосовой модуль стоит 3,5–4,5 тыс. ₽/мес на клиента (18) | Yandex SpeechKit, Voximplant или Zadarma |
| Бронирование, депозиты, банкеты | **Партнёрство / white-label** | Рынок занят: Restoplace, Remarked, Leclick (12, 14) | Restoplace (есть тариф от 0 ₽). Сами делаем только сценарий подтверждения брони за 24 и 3 часа |
| Wallet-лояльность | **White-label / партнёрство** | UDS и Premium Bonus уже готовы. Свою делать нет смысла (11) | Wallet-сервисы, UDS. Наша работа — настроить механику |
| ИИ-ответы на отзывы (Яндекс Карты, 2ГИС, агрегаторы) | **Сами, полуавтоматом** | Дешёвый и быстрый результат, хорошо продаётся (11, 13) | Мониторинг отзывов берём у внешних сервисов, ответы генерирует наш LLM |
| ИИ-фото и описания блюд | **Сами как услуга** (сторонние модели) | Это работа на прикладном уровне, отдельный продукт не нужен | Генеративные API |
| Прогноз спроса и выпечки | **Сами, но после 90 дней** | Много ценности для пекарен, но нужны данные продаж из кассы и время на ML (11) | Сначала пилот на одной пекарне |
| ИИ-консьерж для отелей | **Сами (ядро бота) + интеграция с PMS через партнёров** | Конкурент — Алиса от 500 ₽ за номер (15) | Маркетплейсы TravelLine и Bnovo |
| CRM, рассылки, согласия по 152-ФЗ | **Партнёрство** | Не наш фокус | Кассовые CRM, сервисы рассылок |

## 3. Архитектура (целевая к 90-му дню)

Источник — 19-tech-stack. Это модульный монолит с мульти-тенантностью: по оценке, для команды из 2–3 человек он в 2–3 раза быстрее микросервисов.

```
           Гость                                     Персонал / владелец
   QR → веб-меню (PWA)   Telegram / MAX / VK / (WA для СНГ)   Админка, дашборд
            │                    │                              │
            ▼                    ▼                              ▼
   ┌─────────────────────── API (NestJS или FastAPI) ───────────────────────┐
   │ Tenant + RBAC │ Меню │ Заказы │ Брони-подтверждения │ Отзывы │ Аналитика │
   │ Channel Gateway (единый слой ботов) │ AI Orchestrator (роутинг Lite/Pro) │
   └──────┬──────────────┬──────────────┬──────────────┬─────────────────────┘
          │              │              │              │
   PostgreSQL+pgvector  Redis (очереди,  S3 (фото,     Интеграции:
   (данные по tenant_id, кэш, сессии)    меню, PDF)    iikoCloud API (меню, стоп-лист по вебхукам)
    RAG по меню)                                       Poster API, позже r_keeper
                                                       GigaChat / YandexGPT
                                                       SpeechKit + Voximplant/SIP
                                                       Restoplace, эквайринг СБП
   Хостинг: Yandex Cloud (или Selectel/Timeweb), только в РФ. 3–20 тыс. ₽/мес на MVP [оценка]
```

Правила:
1. **Цены и стоп-лист ИИ берёт только прямым запросом к базе** (function calling), а не из RAG, иначе модель будет выдумывать цены (19).
2. **Роутинг моделей.** Около 80 % запросов уходит на Lite-модели, сложные — на Pro. Получается 400–1 200 ₽/мес на заведение (18).
3. **Обезличивание.** Перед любым вызовом не-российской модели убираем персональные данные. Логи диалогов храним в РФ, согласия записываем.
4. **Шаблоны.** Онбординг строится на шаблонах по сегментам (кофейня, бар, отель). После 20–30 внедрений это сокращает трудозатраты на 40–50 % [оценка] (18).
5. **Наблюдаемость.** Для каждого заведения собираем метрики: число диалогов, расход токенов, конверсию в заказ или бронь. Из них потом делаем свои кейсы «до и после» (20).

## 4. MVP за 30, 60 и 90 дней

### День 0–30: проверить спрос без своей разработки
Бюджет 200–500 тыс. ₽ [оценка] (19).
- QR-меню на white-label или простой статический генератор с нашей админкой-таблицей. Мультиязычность RU/EN, аллергены.
- Бот FAQ и меню на n8n или Salebot + GigaChat Lite, каналы Telegram и MAX.
- ИИ-ответы на отзывы делаем вручную с помощью LLM (без продукта).
- Подтверждение броней — скриптом в мессенджере поверх Restoplace или таблицы.
- Продажи: бесплатный экспресс-аудит меню и отзывов. Лиды берём из Яндекс Карт с фильтром «рейтинг ниже 4,7 и есть отзывы без ответа» (11). Цель — **10 пилотов, из них 3–5 платящих**, в первую очередь кофейни и кафе в 1–2 городах-миллионниках (16).
- KPI: конверсия аудита в пилот ≥ 30 %, время запуска ≤ 5 дней, первые 3 кейса с цифрами «до и после» [оценка].

### День 31–60: своё ядро
- Мульти-тенантная платформа (Postgres + pgvector + Redis + S3), своё QR-меню с админкой.
- Импорт меню и стоп-листа из **Poster** (1–2 нед.) и **iiko** (2–3 нед.), пока только чтение (19).
- Channel Gateway: Telegram + MAX + VK, RAG по меню, функция «позвать официанта / кальянщика» (14).
- Переносим пилотных клиентов с no-code на свою платформу.
- Пакеты: **Старт** (15 тыс. ₽ + 1 990–2 990 ₽/мес) и **Бизнес** (45 тыс. ₽ + 6 990 ₽/мес) (18, 11).
- Цель: 20–25 клиентов на абонплате, средняя абонплата ≥ 5 тыс. ₽ [оценка].

### День 61–90: модули, которые поднимают средний чек
- **«Без пустых столов»**: подтверждение брони за 24 и 3 часа, предоплата через СБП (партнёр). Пилоты в барах и fine dining (12, 14).
- **ИИ-отзывы как продукт**: мониторинг и черновики ответов с одобрением в один клик.
- **Пилот голосового ИИ-администратора** (SpeechKit + Voximplant) у 1–2 клиентов, модуль от 9 990 ₽/мес (18).
- **ИИ-консьерж для отеля**: пилот на 1 отеле, QR в номере ведёт в бот в MAX или Telegram с меню рум-сервиса (15).
- Партнёрская программа для интеграторов iiko: 15–30 % от первого платежа (17).
- Цель на 90-й день: **40–60 клиентов**, доля пакета Бизнес и выше ≥ 40 %, отток ≤ 3 %/мес [оценка]. Точка безубыточности — около 60 клиентов при средней абонплате от 8 тыс. ₽ (18).

### После 90 дней
r_keeper, отправка заказов в кассу и оплата со стола, прогноз выпечки (Пекарня Про от 14 900 ₽/мес), ИИ-сомелье, выход в Казахстан (WhatsApp, Kaspi QR), CRM-пакет для сетей (250 тыс. ₽ + 35 тыс. ₽/мес).

## 5. Приоритизация услуг

Шкалы от 1 до 5 [оценка]: **спрос** — насколько широко и остро болит; **маржа** — валовая маржа и чек; **сложность** — разработка, внедрение и риски. **Приоритет = спрос × маржа ÷ сложность.**

| # | Услуга | Цена (ориентир) | Спрос | Маржа | Сложность | Балл | Решение |
|---|---|---|---|---|---|---|---|
| 1 | ИИ-ответы на отзывы и рейтинг | 5–15 тыс. ₽/мес за точку (13) | 5 | 4 | 1 | **20,0** | Делаем сразу, с 30-го дня |
| 2 | Бот FAQ и меню (TG + MAX + VK) | 30–45 тыс. ₽ + 6 990 ₽/мес (18) | 4 | 5 | 2 | **10,0** | Ядро, с 30-го дня |
| 3 | Аудит меню и меню-инжиниринг | 25–50 тыс. ₽ разово (13) | 4 | 4 | 2 | **8,0** | Лид-магнит и платный аудит |
| 4 | Подтверждение броней / «Без пустых столов» | 60–120 тыс. ₽ + 10–20 тыс. ₽/мес (12) | 3 | 5 | 2 | **7,5** | 60–90 дней, бронь у партнёра |
| 5 | QR-меню (вход) | 15 тыс. ₽ + 1 990–2 990 ₽/мес (18, 11) | 5 | 2 | 2 | **5,0** | Входной продукт, не продаём отдельно без допродажи |
| 6 | ИИ-фото и описания блюд | 10–30 тыс. ₽ разово [оценка] | 3 | 4 | 1 | **12,0** | Допродажа с первых дней, ручная услуга |
| 7 | Свой канал заказов (QR / Mini App) для доставки | 30–80 тыс. ₽ + 3–7 тыс. ₽/мес (13) | 3 | 3 | 3 | **3,0** | После 90 дней, для дарк-китчен |
| 8 | ИИ-консьерж для отелей | 60–120 тыс. ₽ + 8–20 тыс. ₽/мес (15) | 2 | 5 | 3 | **3,3** | Пилот на 90-й день, длинный цикл продаж |
| 9 | Голосовой ИИ-администратор | от 9 990 ₽/мес (18) | 3 | 3 | 4 | **2,3** | Пилот, себестоимость 3,5–4,5 тыс. ₽ |
| 10 | Лояльность в Wallet (настройка) | 2–5 тыс. ₽/мес [оценка] | 4 | 2 | 2 | **4,0** | White-label, в пакете «Старт/Рост» |
| 11 | Ивенты: лендинг, билеты, QR-вход | 40–80 тыс. ₽ (14) | 2 | 3 | 3 | **2,0** | По запросу |
| 12 | ИИ-сомелье | 80–200 тыс. ₽ + 15–30 тыс. ₽/мес (12) | 1 | 5 | 3 | **1,7** | После 90 дней, точечно в премиум |
| 13 | Прогноз спроса и выпечки | от 14 900 ₽/мес за точку (11) | 2 | 4 | 5 | **1,6** | Пилот после 90 дней |
| 14 | Оплата со стола, отправка заказа в кассу | % / абонплата [оценка] | 3 | 2 | 5 | **1,2** | Только через партнёров |

**Вывод.** Первая волна (дни 1–60): отзывы, бот, аудит, ИИ-контент, а QR-меню идёт как вход. Вторая волна (дни 61–90): брони и депозиты, консьерж, пилот голосового ИИ. Тяжёлые интеграции (оплата, прогноз) откладываем на потом или отдаём партнёрам.

## 6. Риски и что с ними делать

| Риск | Вероятность / влияние | Что делаем |
|---|---|---|
| Высокий отток на дешёвом QR-меню (20–30 % в год) | Высокая / высокое | Годовая предоплата, перевод клиентов со Старта на Бизнес. +1 п.п. оттока снижает LTV примерно на 25 % (18) |
| Мало клиентов до точки безубыточности (95–110 на средней абонплате) | Средняя / высокое | Расти по средней абонплате (+1 000 ₽ сдвигает точку на 15–20 клиентов), держать no-code старт, не нанимать людей раньше времени |
| 152-ФЗ и выросшие штрафы | Средняя / высокое | Хостинг в РФ, российские LLM для персональных данных, согласия, уведомление РКН, проверка юристом |
| Блокировки и замедление Telegram и WhatsApp | Высокая / среднее | С первого дня работаем мульти-канально (MAX, VK, веб) |
| Галлюцинации ИИ: неверные цены, аллергены | Средняя / высокое | Цены берём только из БД, перевод аллергенов проверяем вручную, человек одобряет ответы на отзывы |
| Зависимость от API iiko, r_keeper и агрегаторов | Средняя / среднее | Сначала Poster и iiko, доступ через дилеров и партнёрство, абстрактный слой коннекторов |
| Кассовые экосистемы и интеграторы делают свой аналог | Средняя / среднее | Позиционирование «результат под ключ», партнёрская комиссия интеграторам |
| Конкуренция с Яндекс Алисой в отелях | Высокая / среднее | Берём мессенджеры без железа, мультиязычность (ZH, AR, TR), F&B-фокус |
| Изменения у поставщиков ИИ (SaluteSpeech, рост цен) | Средняя / низкое | Два провайдера на каждый тип API, роутинг моделей |
| Гости негативно воспринимают депозиты | Средняя / среднее | Предоплата за сет, условия письменно до визита (14, 12) |
| Сезонность продаж (летом заведения перегружены) | Высокая / низкое | Основные продажи в сентябре–ноябре и январе–марте, летом готовим продукт |
| Нет публичных российских кейсов | Высокая / среднее | Собираем свои кейсы «до и после» с первых 10 пилотов (20) |

## 7. Метрики контроля дорожной карты

- Время запуска клиента: QR-меню ≤ 5 дней, бот ≤ 2 недели.
- Средняя абонплата: ≥ 5 тыс. ₽ к 60-му дню, ≥ 7 тыс. ₽ к 90-му [оценка].
- Себестоимость LLM ≤ 10 % абонплаты (18).
- Отток ≤ 3 %/мес; LTV/CAC ≥ 4; CAC ≤ 15 тыс. ₽ (18, 17).
- Доля клиентов с хотя бы одним ИИ-модулем ≥ 50 % к 90-му дню.
