# Подача.AI: QR-меню и ИИ-автоматизация для заведений

Сайт сервиса для ресторанов, кафе, кофеен, баров, доставки и отелей (HoReCa) в России и СНГ. Мы продаём QR-меню, оптимизацию процессов и ИИ-автоматизацию: ИИ-официант в меню, ИИ-администратор бронирований (мессенджеры и телефон), центр отзывов, ИИ-аналитик продаж поверх iiko и r_keeper, прогноз закупок, распознавание накладных, контент и CRM-рассылки.

## Структура

```
site/                 статический сайт (без сборки)
  index.html          главная: услуги, прайс, пакеты, ROI-калькулятор, сравнение, FAQ, заявка
  market.html         аналитика рынка: цифры, сегменты, боли, конкуренты с ценами, тренды, право, источники
  assets/style.css    общие стили (CSS-переменные, светлая и тёмная тема через prefers-color-scheme)
  assets/app.js       каталог услуг и прайс, калькулятор окупаемости, меню, форма (mailto)
research/             исследования рынка (Markdown, со ссылками на источники)
  00-strategy.md      итоговая стратегия: услуги, пакеты, прайс, ROI, позиционирование
  01–18-*.md          рынок, конкуренты, POS, ИИ-направления, сегменты, регионы, продажи, юнит-экономика
```

Зависимостей нет: чистые HTML, CSS и vanilla JS, из внешнего подключаются только шрифты Google Fonts (Inter, Manrope).

## Как открыть локально

Откройте `site/index.html` в браузере. Или запустите локальный сервер:

```bash
cd site && python3 -m http.server 8080
# http://localhost:8080
```

## Деплой

**GitHub Pages.** Settings → Pages → Source: GitHub Actions, используйте шаблон «Static HTML» и укажите `path: site`. Проще вариант: перенести содержимое `site/` в папку `docs/` и выбрать Deploy from branch → `/docs`.

**Любой статический хостинг** (Netlify, Vercel, Cloudflare Pages, Yandex Object Storage, Selectel, обычный nginx): опубликуйте папку `site/` как корень сайта, команда сборки не нужна.

## Перед запуском заменить

- `https://t.me/your_handle` на ваш Telegram (в `index.html` и `market.html`).
- `hello@podacha.ai` в `assets/app.js` на реальную почту для заявок.
- Цены в массиве `S` в `assets/app.js` и пакеты в `index.html`.
- Если форма будет собирать данные на сервере: политика ПДн, отдельное согласие (152-ФЗ) и хостинг в РФ.

## Про данные

Цифры рынка взяты из открытых источников 2025–2026 годов, ссылки есть в `research/` и в разделе «Источники» на `market.html`. Пометка «оценка» означает наш расчёт или экспертный диапазон. Цены конкурентов меняются, поэтому перед публикацией их стоит перепроверить.
