## 3. Где пробелы (что можем закрыть мы)

1. **ИИ-слой поверх POS отсутствует или фрагментарен.** Ни у одной системы нет зрелого "ИИ-управляющего": чтение данных продаж + рекомендации на естественном языке. Мы: Telegram-бот/дашборд "спроси свои продажи" через iikoCloud API / Poster API / Saby API — 15–40 тыс. ₽ внедрение + 3–8 тыс. ₽/мес (**оценка нашей цены**).
2. **Прогноз спроса и закупок.** Есть у iiko в виде партнёрских модулей и у сетевого энтерпрайза; у малых (Quick Resto, Poster, Frontpad) — нет. Списания в HoReCa 4–10% себестоимости (**оценка**), прогноз даёт −20–30% списаний.
3. **ИИ-приём заказов (бот/голос) для доставки.** Frontpad/iiko имеют колл-центр, но не ИИ-оператора. Мы: бот в Telegram/WhatsApp/MAX + голосовой ИИ с записью заказа в POS через API.
4. **Отзывы и репутация.** POS не работают с Яндекс Картами/2ГИС. Мы: ИИ-ответы на отзывы, сводка жалоб → связь с чеками.
5. **QR-меню с ИИ-апсейлом и мультиязычием.** Встроенные QR у POS — статичные. Мы: QR-меню с рекомендациями, переводом, фото-генерацией, синхронизацией стоп-листа из POS.
6. **Персонализированные рассылки по базе лояльности.** Лояльность есть, сегментации и генерации текстов — нет. Мы: RFM-сегменты + ИИ-тексты, интеграция iikoCard/Saby/Poster.
7. **Сквозная аналитика между системами** (POS + агрегаторы Яндекс Еда/Delivery Club + реклама). Мы: BI на базе выгрузок API.
8. **Интегратор-сервис для малых.** Quick Resto/Poster/Frontpad продаются self-service, внедрение/настройка техкарт часто некому делать — рынок для фиксированных пакетов "настройка под ключ".
9. **Обучение персонала / регламенты.** ИИ-ассистент по техкартам и стандартам для официантов/поваров — не закрыт ни одной POS.

## 4. Стратегия интеграций (приоритет)
1. **iiko** — самая большая доля рынка ресторанов РФ (оценочно 30–40% в среднем сегменте, **оценка**), лучший облачный API → приоритет №1.
2. **r_keeper** — сети и отели, сложнее интеграция, но выше чеки клиентов.
3. **Saby Presto** — быстро растёт за счёт экосистемы СБИС; хороший API.
4. **Quick Resto / Poster** — кофейни и малые кафе: массовый сегмент для пакетных тарифов.
5. **Frontpad** — доставки: продаём ИИ-приём заказов и прогноз.

Позиционирование: "Мы не заменяем вашу кассу — добавляем ИИ поверх iiko/r_keeper/Saby/Quick Resto/Poster/Frontpad".
