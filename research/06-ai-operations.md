# 06. ИИ в операционке заведений: рынок, решения, цены

Дата: октябрь 2026. Цены в RUB. Пометка **(оценка)** значит экспертную оценку, а не подтверждённые источником данные. Публичных прайсов на ИИ-модули для HoReCa в РФ мало, большинство вендоров даёт цену «по запросу». Поэтому перед публикацией на сайте цены конкурентов нужно проверить.

## 1. Краткие выводы
- Кейс с самым громким измеримым эффектом: прогноз закупок в Dodo Brands на Microsoft AI. Компания ожидает экономию **до 54 млн ₽/год** ([Microsoft](https://news.microsoft.com/ru-ru/dodo-brands-ai-microsoft/)).
- Сегмент цифровых решений для HoReCa вырос на **15–18% в 2024**, рост продолжился в 2025 ([retail.ru](https://www.retail.ru/rbc/pressreleases/bolshaya-khoreka-kak-ii-vliyaet-na-gostinichnyy-i-restorannyy-biznes/)).
- Основная учётная система рынка — iiko (а также r_keeper и Saby Presto). Данные о чеках и почасовой выручке можно забирать через iikoServer API ([Habr](https://habr.com/ru/articles/1000858)). Поэтому самый дешёвый вход для нас — **надстройки над iiko/r_keeper**, а не своя POS.
- В iiko есть складской учёт: приёмка, инвентаризации, списания ([КП](https://www.kp.ru/money/biznes/programma-iiko/)). Распознавания накладных ИИ из бумаги или фото в открытых описаниях не видно. Значит, OCR накладных — свободная ниша для малых заведений. С 2024–2025 растёт доля ЭДО и «Меркурия», но у малых точек остаётся много бумаги.
- Для видеоаналитики касс в РФ есть готовые продукты, например Trassir ActivePOS (DSSL) для контроля кассовых операций ([retail.ru](https://www.retail.ru/articles/umnaya-videoanalitika-v-riteyle-klyuch-k-effektivnomu-upravleniyu-i-kontrolyu-biznesa/)). Наша роль здесь — интеграция и настройка, а не разработка.
- Отдельный мотив для контроля касс — контроль ФНС за кассами в общепите (проект «Общественное питание») ([Saby](https://saby.ru/articles/presto/obschepit_v_2025_godu_chto_novogo)).

## 2. Направления: что даёт ИИ и какой эффект

| Направление | Что делает | Типичный эффект (оценка, по отраслевой практике) | Сложность для нас |
|---|---|---|---|
| Прогноз спроса и закупок | Прогноз продаж по блюдам по дням и часам с учётом погоды, праздников и истории, затем автозаказ | списания −20…40%, фудкост −1…3 п.п. | средняя (нужны данные из POS за 6–12 мес.) |
| Контроль себестоимости и техкарт | Сверка закупочных цен с техкартами, алерты при росте цены, пересчёт маржи блюд, ABC/menu engineering | +2…5 п.п. валовой маржи меню | низкая–средняя |
| Графики смен | Прогноз загрузки по часам и генерация графика под нормы трудового законодательства | ФОТ −5…12% | средняя |
| OCR накладных | Фото или скан УПД/ТОРГ-12 превращается в приходную накладную в iiko/1С с сопоставлением номенклатуры | 3–10 ч/нед бухгалтера или управляющего, меньше ошибок | низкая (LLM + vision API) |
| Видеоаналитика: очереди | Подсчёт людей в очереди и времени ожидания, алерты «открыть вторую кассу» | время ожидания −15…30% | средняя (камеры + ПО) |
| Видеоаналитика: кражи и кассы | Сопоставление видео с чеками: отмены, возвраты, «пробитие без гостя» | потери −30…70% от выявленных схем | интеграция готовых решений |
| Видеоаналитика: чистота, гигиена, СИЗ | Шапки, перчатки, мытьё рук, уборка зала по регламенту | меньше штрафов Роспотребнадзора | средняя–высокая |
| Контроль качества кухни | Фото блюда на раздаче сравнивается с эталоном (выход, сервировка), контроль времени отдачи | меньше жалоб, единый стандарт в сети | средняя |
| Анализ чеков | Средний чек, допродажи, корзины (association rules), аномалии у официантов, LLM-отчёт собственнику текстом в Telegram | средний чек +3…8% | низкая |

## 3. Решения на рынке и цены

| Решение | Направление | Цена (публичная / оценка) |
|---|---|---|
| iiko (базовая лицензия + модули склада и отчётов) | учёт, склад, техкарты, базовое прогнозирование ([a2is](https://a2is.ru/catalog/programmy-dlya-kafe-i-restoranov/iiko)) | ~3–6 тыс. ₽/мес за точку плюс модули (оценка) |
| r_keeper / StoreHouse | склад, себестоимость | ~2–5 тыс. ₽/мес (оценка) |
| Saby Presto | POS, склад, ЭДО, распознавание документов в экосистеме Saby | от ~1–3 тыс. ₽/мес (оценка) |
| Trassir ActivePOS (DSSL) | видео + кассовые события | лицензия по запросу; ориентир 15–40 тыс. ₽ на кассу разово (оценка) |
| Ivideon / облачные видеосервисы с аналитикой | очереди, подсчёт людей | ~1–3 тыс. ₽/мес за камеру с аналитикой (оценка) |
| Специализированные сервисы прогноза закупок (enterprise, по модели Dodo + Microsoft) | прогноз | проекты от 1 млн ₽ (оценка) |
| Конструкторы графиков смен (e.g. облачные WFM) | смены | ~300–700 ₽/мес за сотрудника (оценка) |
| Универсальные OCR (Яндекс Vision OCR, ABBYY) | накладные | API — копейки–единицы ₽ за страницу; готовые интеграции с 1С от 2–5 тыс. ₽/мес (оценка) |

Вывод: крупные сети закрывают задачи enterprise-проектами за миллионы рублей. Малые и средние заведения (1–10 точек) остаются без доступного ИИ: у них iiko «как есть» и Excel. Это и есть наш сегмент.

## 5. Риски
- Качество данных в iiko у малых заведений низкое: техкарты не актуальны, инвентаризации нерегулярные. Решение — продавать первым этапом «аудит и чистку данных».
- Видеоаналитика затрагивает персональные данные (152-ФЗ): нужны уведомление сотрудников и согласия.
- Доступ к API iiko/r_keeper может быть платным или требовать партнёрства с дилером.
- Использование зарубежных LLM ограничено. Лучше закладывать YandexGPT или GigaChat либо локальные модели.
